# 音声・音・字幕

## VOICEVOX

- GPU 版を docker で `127.0.0.1:50021` に立てる ([setup.md](setup.md))。
- 話者と話し方は `config/voice.yaml`。ずんだもん (ノーマル) speaker 3・speedScale 1.05・intonationScale 1.15、四国めたん (ノーマル) speaker 2・1.0・1.1。
- 音声と問い合わせの結果は `cache/voicevox/` にたまる (文とユーザー辞書の中身で決まる)。辞書を変えると作り直しになる。

### キューの時刻

キュー `{name}` の時刻は、「キューの直前までの文」を audio_query して拍 (mora) の数 k を数え、
文全体の拍の時刻表で k 番目の拍が始まる時刻とする (`zunda/voice.py`)。
字幕のページ送りの時刻も同じ方法で決まる。

### 読みを確かめる

台詞を書いたら、`build/voice/SNN.json` の各台詞の `kana` を全部読んで誤読を探す。直し方は 3 つ。

| 直し方 | 使う所 | 例 |
|---|---|---|
| ルビ `[表記\|よみ]` (PLAN.md) | その台詞だけ | `[FF D8\|エフエフ、ディーハチ]`、`[100分の1秒\|ひゃくぶんのいちびょう]`、`[大あり\|おおあり]`、`[小箱\|こばこ]`、`[開けない\|ひらけない]` |
| ユーザー辞書 (`config/readings.yaml` の `user_dict`、動画固有は `video.yaml`) | 用語 | `[GIF, ジフ, 1]`、`[LZW, エルゼットダブリュー, 7]`、`[VP8L, ブイピーエイトエル, 6]` |
| 読み替え (`reading_fix`、正規表現) | どの台詞でも起きる誤読 | 値→あたい (ネ)、行→ぎょう (クダリ)、表→ひょう (オモテ) |

よくある誤読：

- 漢字の訓読み・音読みの取り違え (値・行・表・大あり)。
- 「〜分の〜」が「ふん」になる (100分の1 → ヒャップンノイチ)。ルビで直す。
- 数字＋英字が数字として読まれる (0A → ゼロアンペア)。`reading_fix` でカタカナにしてから、そのカタカナを辞書に入れる。
- 16 進のバイト列は、ルビで読みを書く (`[B5 00|ビーご、ゼロゼロ]`)。
- 英字と数字が混ざった名前 (VP8L) は、ルビで読みを書いても 1 文字ずつ区切って読まれる。辞書に 1 語として入れる。
- かぎかっこで引用した「はい」が助詞の「は」として「ワ」と読まれる (「7回は『はい』」→ナナカイワワイ)。`[はい|ハイ]` のようにカタカナのルビにする。
  「はいかいいえ」も切れ目を間違えるので `[はいかいいえ|ハイか、イイエ]`。
- 無声化で別の音に聞こえる (「圧縮」の「シュ」がアッスクに聞こえる)。`config/voice.yaml` の `revoice` に入れた拍は有声に戻す。

### 間

`config/voice.yaml` の `gaps`、`sentence_pause`。動画ごとに `video.yaml` の `voice:` で上書きできる。

- 台詞と台詞の間：同じ人 0.4 秒、話し手の交代 0.55 秒、「？」で終わった問いかけへの返事 0.75 秒。
- 1 つの台詞の中の文の切れ目 (。！？)：VOICEVOX は読点とほぼ同じ長さしか休まないので、0.55 秒以上にする。
- 台詞の行末の ` (+秒)` は、これらに足される。

## 音の仕上げ (`zunda/master.py`、`config/audio.yaml`)

- 声・効果音・BGM を混ぜ、全体を **−14 LUFS** にそろえる。リミッターのあとで測り直して合わせる。
- BGM は台詞の間だけ下げる (ダッキング、−9dB)。台詞のすき間が 2 秒未満なら下げたままにする (会話の途中で上がったり下がったりさせない)。
  長い間に入ったときだけ 1.2 秒かけて戻し、次の台詞の 0.3 秒前から下げる。
- BGM はシーンごとに曲を選べる (`video.yaml` の `bgm`)。曲の切り替わりは 1.5 秒のクロスフェード、最後は 2.5 秒でフェードアウト。
- 効果音は意味のある瞬間だけ (1 シーン 3 回まで)。
- BGM (甘茶の音楽工房) の曲を使った動画を YouTube の Content ID に登録してはいけない ([publishing.md](publishing.md))。

## 字幕 (`zunda/subtitle.py`)

- 2 人の間の下端 (`SUB_BOX`) に、白い文字＋話し手の色の縁取り (M PLUS Rounded 1c ExtraBold 50px)。文字の閉じた隙間も縁取りの色で埋める。
- 1 ページ最大 2 行。入りきらない台詞はページ送りにし、ページの切り替えは読み上げの位置に合わせる。
- 改行とページの位置は、BudouX で分けた文節の切れ目から、台詞全体で最も自然な組み合わせを選ぶ。自然さの順は
  句点の後 ＞ 読点の後 ＞ それ以外。言葉の途中 (BudouX が「動か｜す」のように分けることがある)、かぎかっこの中、
  極端に短い行やページ (「あ、」だけ) は避ける。2 行の長さはなるべくそろえる。
- 不自然な区切りは、台詞を短くするか読点を入れて直すのがいちばん確実。
