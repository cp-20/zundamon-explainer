# 公開

## タイトル

- 案を 4〜5 個出し、それぞれのねらい (シリーズで揃える/意外さで引く/検索に強い用語を入れる、など) を添える。最後に推しを 1〜2 個。
- 数字を入れるなら実データの値 (「6.9MBの画像が333KBに！？」「8枚の絵がPNG1枚より小さい！？」)。
- 末尾に「【ずんだもん解説】」。
- 公開に使ったタイトルは `video.yaml` の `title` に書く。

## サムネイル (1280×720)

- 動画ごとに `videos/<name>/tools/thumbnail.py` に案を関数で書く (`thumb_a()` …)。共通部品は `zunda/thumb.py`
  (立ち絵の切り抜き `chara()`・`face()`、極太の文字 `heavy()`、札 `pill()`・`black_tag()`、◎✕ `mark()`、吹き出し `bubble()`、`＞＞＞` の `chevrons()`、背景 `spot_bg()`)。
  `ZX_VIDEO=<name> uv run python videos/<name>/tools/thumbnail.py b` → `videos/<name>/build/out/thumbnail_B.png`
- 4 案くらい出して、並べた画像を見て崩れ (文字のはみ出し・重なり・キャラの切れ) を直してから渡す。
  YouTube の一覧の大きさ (幅 360px と 246px) に縮めた画像も並べて、文字と主役の絵が読めるかを見る。
- 数字は実データから計算し、`assert` で確かめる。
- これまで反応がよかった作り：
  - 数字の落差を棒グラフで見せる型 (シリーズで揃えられる)。
  - 題材の「中身」を見せる型 (DCT の 64 の模様、コマの並び) ＋大きな一言。
  - 大きな一言は 2〜3 段に分けて、いちばん大事な語をいちばん大きく黄色に。キャラは驚いた表情で角に。
- 「もっとインパクトを」と言われたら：主役の絵を画面いっぱいに、色数をしぼって (2 色など) コントラストを上げ、一言をさらに大きく。
- 「もっと洗練させて」と言われたら、再生数の多い動画のサムネを実際に集めて見比べる (YouTube の検索を再生数順にして、i.ytimg.com のサムネを並べる)。
  WebP 編で見た、和文の解説動画 (100 万回以上) に共通する作り：
  - 字は丸くない極太のゴシック (Dela Gothic One。`heavy()`)。白い内側の縁と黒い外側の縁。大事な語だけ赤・黄のグラデーション。
  - キャラは顔と腕を大きく切り抜き、白いステッカーの縁で画面の角からはみ出させる (`face()`)。
  - 主役の絵は 1 つ。文字は 2 行まで。前後の比べは赤から黄の「＞＞＞」。
  英語の画像圧縮の解説 (Branch Education など) は、文字を減らして具体的な 1 枚の絵 (崩れた画素となめらかな画素) で見せている。
- 比べる絵は「この差！？」で終わらせず、どちらが勝ったかを言い切る (「どちらも 4KB」→ JPEG ✕ カクカク / WebP ◎ なめらか →「WebPの圧勝！」)。
  条件 (同じ大きさ) を先に、結果を印で、結論を一番大きな字で。
- 公開に使った案は `video.yaml` の `thumbnail` に書く。

## 概要欄

- `tools/description.py` が `video.yaml` の `description`・`chapters` と、`config/assets.yaml` の `credits` (＋`extra_credits`) から作る。
  チャプターの時刻は各シーンの音声の長さから計算する。
- シリーズの前の動画へのリンクは `description` の中に「■ シリーズ」として書く。

## クレジット

- 動画の最後にクレジットの画面を出す (音声・立ち絵・音楽・効果音・フォント・映像、動画ごとの素材)。内容は概要欄と同じにする。
- VOICEVOX の音声は「VOICEVOX:ずんだもん」「VOICEVOX:四国めたん」の表記が必要。

## YouTube へのアップロード (Chrome の YouTube Studio を操作する)

- 動画のファイル (数十 MB) はブラウザの道具から渡せない (10 MB まで)。「ファイルを選択」だけは依頼者にしてもらい、残りを入力する。
  サムネ (1280×720 の JPEG) は道具から渡せる。
- 設定は前の動画にそろえる：子ども向けではない、年齢制限なし、有料プロモーションなし、AI の使用「いいえ」、リミックスを許可、
  標準の YouTube ライセンス、カテゴリ「ブログ」、コメントはオン (全員・標準)、登録者に通知、チャプターの自動生成を許可。
  迷ったら前の動画の編集画面を開いて、選ばれている項目を読む。
- カード：前の動画の知識を使う場面に、その動画へのカードを置く。**1 本の動画へのカードは 1 枚まで** なので、前の動画ごとに一番大事な場面を 1 つ選ぶ。
  時刻の欄は「分:秒:フレーム」 (2:32 は `02:32:00`)。時刻を入れるとカードの並びが入れ替わるので、メッセージとティーザーを先に入れて時刻は最後に。
  メッセージは「〇〇はここで解説」、ティーザーは「PNG編」のように短く。
- まず **非公開** で保存し、依頼者が確かめてから公開にする。公開したら、ログインしていない状態で再生できるかを確かめる。
- 公開したら `video.yaml` の `youtube` と動画の README に URL を書き、`main` を push してから Release を作る (Release の本文がリポジトリのフォルダを指すため)。

## 成果物の置き場所

- 動画 (1080p の mp4)、サムネ、概要欄は GitHub の Release に置く (タグは `<name>-v1` など)。リポジトリには入れない。
- Release の本文に YouTube のリンクと、使ったタイトル・サムネを書く。
