# 確かめ方

自動の検査は完全ではない。検査 0 件は出発点で、そのあと必ず目で見る。
報告では、確かめたことと確かめていないことを分けて書く。

## 自動の検査 (`tools/check.py`)

`bin/pipeline.sh` と `bin/build_all.sh` が実行し、`build/check/SNN.txt` に書く。検出するもの：

| 項目 | 内容 |
|---|---|
| はみ出し・領域侵入 | 画面の外、立ち絵・字幕の領域 (立ち絵の実際の形で判定) |
| 重なり | 文字どうし、文字と図、文字と枠線、閉じた枠線どうしの交差 |
| 一瞬の文字 | 読むのに足りない時間しか出ない文字 (2.5 秒以上、0.15 秒/字。書き換わる途中の文字は 1.5 秒以上) |
| 小さい文字 | 字面の高さが小さすぎる文字 |
| 遅れ | キューに間に合わなかったアニメーション |
| 止まった画面 | 台詞の間に 6 秒以上動かない画面 |
| 長さ | 映像と音声の長さの不一致 |
| ちらつき | 前後は止まっているのに、1 フレームだけ画面が大きく変わる所 (消し方の不具合) |

## シートとフレーム

- `tools/sheet.py` が、アニメーションが落ち着いた状態ごとのフレームと、その時の台詞を並べた `build/sheet/SNN.png` を作る。全部見る。
- シートは縮小なので、気になる所・遷移の途中は ffmpeg で切り出して見る：
  `ffmpeg -ss <秒> -i build/out/SNN.mp4 -frames:v 1 -vf scale=960:540 x.png`
- 数秒の範囲を並べて見ると、一瞬の消え・ちらつきが分かる：
  `ffmpeg -ss <秒> -t 3 -i build/comp/SNN.mp4 -vf "fps=10,scale=320:180,tile=8x3" t.png`
- 見ること：読めない小ささ、上の帯だけに詰まっていて中央が空いていないか、重なり、消し忘れ、意図した変化 (例：段・ディザの差) が本当に見えるか。

## 通しの確かめ

- 全シーンの検査 0 件。
- シーンのつなぎ目：前のシーンの最後と次のシーンの最初のフレームの差 (平均の画素差がほぼ 0)。
- 音量：`master` が出力する LUFS が −14 前後。
- 1080p の本番から何枚か切り出して、文字の大きさと読みやすさ。
- 概要欄のチャプターの時刻と名前。

## 音

- 音声はエージェントには聞けない。読みは `kana` の文字列で確かめ、聞いていないことを報告に書く。
- 誤読の直し方は [audio-and-subtitles.md](audio-and-subtitles.md)。

## 共通部品を直したとき

- `zunda/` や `config/` を直したら、他の動画のシーンも壊れていないか確かめる：
  各動画で `bin/voice.sh <name>` のあと、全シーンを低い解像度で描いて検査する (`bin/render.sh <name> SNN 270` と `tools/check.py`)。
