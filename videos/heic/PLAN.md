# HEIC解説動画 — 計画

ずんだもん (Z・聞き手) と四国めたん (M・解説)。PNG 編・JPEG 編・GIF 編・WebP 編の続編。想定 15〜17 分。1920×1080 / 30fps。
対象は普通の高校生。前提にしてよい知識：16 進数、前の 4 本で出てきた言葉 (フィルタ、ハフマン符号、明るさと色、波に分ける、割って丸める、
上と左から予想、算術符号の定規、ループフィルタ)。

## 書式

docs/script-writing.md を参照 (`> Z:` / `> M(笑):`、`{cue}`、`[表記|よみ]`、行末の `(+秒)`、`→` は画面の案)。

## 素材 (data/)

- `cat.png`：猫の写真 451×300 (scikit-image の chelsea、CC0)。前の 4 本と同じ。
- `cat_q45.heic`：pillow-heif (libheif + x265) の品質 45。**本編の HEIC**。13,368 バイト。元とのずれ (RGB の平均) 2.65 が、
  JPEG 品質 80 (`cat_q80.jpg`、23,693 バイト、2.61) と WebP 品質 80 (`cat_q80.webp`、16,974 バイト、2.72) の間になる品質を選んだ。
- `cat_q25.heic` (3,791 バイト)・`cat_q15.heic` (2,077 バイト)：品質を下げたもの。`cat_q5.jpg` (3,797)・`cat_q10.webp` (3,898)：JPEG 編・WebP 編と同じ。
- `zunda.heic`：透明とサムネイルつきのずんだもん (立ち絵から作るのでリポジトリには入れない。`tools/make_data.py`)。
- 画面の数値はすべて自前の読み取り器から取る：`tools/heif.py` (箱)、`tools/hevc.py` (HEVC の復号器)。
  自前の復号器は ffmpeg と Y・U・V の全画素が一致 (`cat_q15` `cat_q25` `cat_q45` のすべてと、x265 の道具を 1 つずつ切り替えた試しのファイル)。

## 主役のブロック

- 四分木の見本：**64×64 の (横 2, 縦 2)** = 画素 (128, 128) から 64×64。左目の下のふち。
  上半分 (目のふち) は 16・8・4 まで割れ、下半分 (毛) は 32×32 のまま。割る？の答えは
  64:1 → 32:1 (16:1, 16:1, 16:0, 16:1) → 32:1 (16:1, 16:0, 16:0, 16:0) → 32:0 → 32:0。

## 画面の約束

- 色：予想はシアン `CYAN`、元 − 予想 の差は紫 `PURPLE`、注目は黄、失われる・ずれは珊瑚、まだ作っていない所は暗く沈める。
- ブロックの大きさの色 (線の色)：64 白、32 青 `BLUE`、16 緑 `#7fd18b`、8 砂 `#e8c36a`、4 橙 `#f08a5d`。どの場面でも同じ。
- 「割る？」の答え：はい＝1 (黄)、いいえ＝0 (暗い灰)。
- CABAC の「はい」の側は青、「いいえ」の側は珊瑚 (WebP 編の定規と同じ)。
- 何度も戻ってくる図：猫の写真と 64×64 の格子 (S03〜S06)。同じ位置・同じオブジェクトで戻す。

## S07 確率を覚えながら書く

> M: {s07_01}最後は書き方。{ruler}WebPでやった算術符号を覚えてる？ {wide}出やすい答えほど、定規を広く取ったわね。

→ {ruler} WebP 編と同じ見た目の定規 (0〜1)。「はい」(青) と「いいえ」(珊瑚) の幅。

> Z: {p}確率が分かっていれば、1ビットより少なく書けたのだ。

> M: {webp}WebPは、{head}その確率をファイルの頭に書いておいたの。{heic}HEICは、{learn}読みながら確率を覚えていくわ。{name}「[CABAC|キャバック]」という方法よ。

→ {head}「WebP：確率の表を先に書く」。{learn}「HEIC：答えを読むたびに確率を直す」。{name}「CABAC」。

> M: {ex}たとえば、波のブロックの中の{q}「この数は0じゃない？」という問い。{start}最初は「[はい|ハイ]」は{p6}6%くらいと思っているの。

→ {q} 問いのカード。{start} 確率のメーター (はい 6%、実際の初期値から)。

> M: {read}でも読んでいくと、{often}「[はい|ハイ]」が思ったより多い。{fix}そのたびに確率を少しずつ直していくわ。 (+0.8)
